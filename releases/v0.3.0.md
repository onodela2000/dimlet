## 使い始めるまで

1. 上のリンクからZIPをダウンロードし、ダブルクリックで展開。
2. 出てきた **Dimlet.app** を **アプリケーション** フォルダへ移動。
3. **Dimlet.app** を開く。画面上部のメニューバーに小さなモニターが表示されます。

起動時は英語です。メニューの **Language → 日本語** で切り替えられます。

**更新する方：** 起動中のDimletをメニューから終了してから、アプリを置き換えて開いてください。

<details>
<summary><strong>English installation instructions</strong></summary>

Download the ZIP linked above. This single file works on both Apple Silicon and Intel Macs running macOS 13 or later.

1. Unzip the download.
2. Drag **Dimlet.app** into **Applications**.
3. Open it and click the little monitor in the menu bar.

For updates, quit the previous Dimlet before replacing the app. The current release is not Apple-notarized; if macOS blocks the first launch, follow the [installation guide](https://github.com/osakanasoft/dimlet#install).

## できること

- **外部モニターだけ暗くする**：内蔵画面はそのまま。
- **すべてのモニターを暗くする**：内蔵画面も含めて黒表示。

黒い画面をクリックすると元に戻ります。アプリの起動中はMacの自動スリープを防ぎます。
